Sequence 2 — “plugging in capabilities”

Five directions for THE BUILD / ENGINE step. Each loops + cycles providers. Pick one (or mix).

01

Dock / motherboard

Product is the core; capability modules fly in and dock to slots around it, connectors pulse.
02

Ports + cables

Product up top with ports; cables draw up from each capability card and light the ports green.
03

Install checklist

App-store style: rows fill in one-by-one with progress + check, provider name cycling in a pill.
04

Stacked layers

Capabilities snap on as layers building up into “your product”. Vertical assembly.
05

Radial hub

Product at the hub; capabilities ring around it and energize one at a time along spokes.
06

Skewed marquee + morphing site ← newest

Bold skewed tech marquee scrolling opposite ways (dimmed bg); foreground browser morphs landing → store → blog.
