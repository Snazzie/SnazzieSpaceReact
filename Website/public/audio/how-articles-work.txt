These are stripped from the display entirely. ... Audio generation. ... A Python script runs locally before committing. It takes a slug and does five things: ... First, it reads the MDX file with explicit UTF-8 encoding. That matters on Windows, where the default encoding decodes em dash bytes as a euro sign, which OmniVoice then reads as "euro." Every em dash becomes a comma for a natural pause. Regular hyphens stay , "real-time" should sound like "real-time," not "real, time." ... Second, it strips MDX syntax: frontmatter, import/export statements, [EY1 CH T IY1 EH1 M EH1 L] tags, markdown links (keeping the display text), bold, code spans, code blocks. Headers get an ellipsis before and after to create a beat between sections. ... Third, phoneme annotations flip: becomes , dropping the written form. A word substitution map handles terms OmniVoice consistently mispronounces regardless of phoneme markers. ... Fourth, the cleaned text goes to OmniVoice running on CUDA with a reference voice sample. The same wav file is used every time, so every article has the same voice. Speech speed is set to 1.15x , slightly faster than the model default, which reads a little slow. ... Fifth, the output writes to a FLAC file and a waveform JSON. The waveform is 200 normalised peak values between 0 and 1, computed by chunking the audio samples and taking the max absolute amplitude per chunk. ... The player. ... The article page checks at build time whether the FLAC exists. If it does, a player renders above the article body. If not, nothing renders , there's no broken UI or missing element, the section just isn't there. ... The waveform is a element. The 200 peak values draw as rounded bars scaled to canvas height, accounting for device pixel ratio. Bars left of the playhead render full white. Unplayed bars render at reduced opacity scaled by their amplitude, so quieter sections look visually quieter. ... The seek input overlays the canvas at zero opacity. Clicking anywhere on the waveform scrubs the audio without any visible range input. Volume is a separate control. ... The element uses so duration loads on page paint without buffering the file. ...
